# Changelog

## 0.1.0

First release.

- iOS: Screen Time blocking (FamilyControls + ManagedSettings), Apple's app picker, customisable Shield extensions.
- Android: Accessibility Service overlay with system apps, launcher and keyboard always allowed.
- Allowlist and blocklist modes.
- `setShieldOptions()` for block-screen text and colours on both platforms.
- Expo config plugin: entitlements, App Group, Shield extension targets, Android service description.
